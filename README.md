# 根管治疗技耗分离开单

离线运行的根管治疗分项开单页面。它不使用固定总价套餐，而是将技术服务费和耗材费分别录入、分别合计。

## 已实现

- 根管相关技术项目库：项目编码、单位、单价和数量；
- 根管数联动：按“根管”计价的项目会随当前根管数同步；
- “常规根管疗程”和“根管再治疗疗程”快捷加入：它们只加入明细，不设固定套餐价；
- 耗材/药品自定义录入，与技术费分开显示；
- 患者、病历号、牙位、医生、诊断、日期、备注；
- 本地保存、删除、清空、新建和打印。

## 互斥与前置校验

- 牙体开髓引流费仅用于牙髓急症的应急处置；同一牙位进入根管治疗时，不允许作为独立项目与根管治疗项目同时开立；
- 根尖段异物取出（加收）必须先有根管内异物取出费，不能单独加入；
- 根管相关项目不得与显微镜辅助操作相关费用同时收费。当前页面未录入显微镜辅助操作项目，但已在界面提示该规则。

- 根管预备费：013105010050000，142 元/根管
- 根管冲洗费：013105010060000，12 元/根管
- 根管充填费：013105010070000，114 元/根管
- 根管再治疗费：013105010080000，100 元/根管

前期处理及加收项目也已列入页面。耗材不属于该技术服务价格表，必须按机构实际耗材目录和实际使用量填报。

## 使用方式

直接使用浏览器打开 `index.html`。页面不依赖服务端；患者信息和本次开单记录仅保存在当前浏览器。最终收费须由机构按执行标准及临床适应症复核。
