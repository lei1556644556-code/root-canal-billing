# 福建口腔技耗分离开单

离线运行的福建口腔分项开单页面。技术服务项目来自《闽医保〔2026〕45号》附件一，耗材和药品由机构按实际使用情况另行录入。

## 当前能力

- 浏览和搜索福建 114 个口腔医疗服务主项目及其分项；
- 按 10 类临床治疗用途浏览福建 114 个主项目：根管、检查、补牙与牙体保存、洁牙与牙周、拔牙、口腔外科与囊肿、固定修复、活动义齿、正畸、黏膜与唾液腺；
- 只有治疗确实存在不同路径时才显示“治疗类型”，只有确实分期时才显示“本次就诊环节”；
- 根管治疗已整理常规治疗、牙髓急症、根管再治疗和根管内异物取出四个分支；
- 儿童、乳牙、根管异常和根管封药等条件会显示对应分项；
- 依附项目和文件明确规定的互斥项目会在加入时校验；
- 文件价格作为最高限价，技术服务单价只能下调；
- 根管预备和充填按根管数联动，根管冲洗和封药按实际治疗次计量；
- 当前明细、数量和固定单价可以保存为本机常用套餐；
- 套餐支持调用、用当前明细更新和删除；
- 支持耗材录入、实时合计、本地保存和打印。

## 文件结构

- `catalog.js`：福建 114 个主项目、83 个分项及文件价格和明确限制；
- `treatment-rules.js`：按临床治疗流程整理的可选项目、阶段、条件及依据；
- `app.js`：开单、校验、金额、套餐和本地保存逻辑；
- `index.html`：页面结构和样式。

## 套餐口径

套餐保存的是当前收费明细中的项目编码、数量和每项实际单价。保存前应先把各项目单价调整到最终执行价，套餐总价由所有明细相加得到。调用套餐时仍会检查当前价格档位上限。

所有记录和套餐仅保存在当前浏览器，不上传患者信息。最终收费仍须由医疗机构根据实际实施项目、适应症和现行政策复核。
